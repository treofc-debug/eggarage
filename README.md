# Oficina OS — Ordens de Serviço

Sistema web (demo) para oficina mecânica: abertura de OS, checklist técnico, fotos do veículo,
serviços/peças, assinatura digital e geração de PDF com fotos, com envio por WhatsApp ou e-mail.

- Funciona 100% no navegador (dados salvos no próprio aparelho via IndexedDB).
- PDF gerado com jsPDF.
- No celular, os botões WhatsApp/E-mail compartilham o PDF já anexado.

Para rodar localmente: `python -m http.server 5178` e abra http://localhost:5178
